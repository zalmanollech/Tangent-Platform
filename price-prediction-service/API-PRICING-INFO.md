# API Pricing Information for Price Prediction Service

## NewsAPI.org

### Free Tier ✅
- **100 requests per day** (free)
- **Limited to development/testing**
- **No credit card required**
- Sign up at: https://newsapi.org/register

### Paid Plans
- **Business Plan**: $449/month
  - 250,000 requests/month
  - Commercial use allowed
  - Priority support

- **Enterprise Plan**: Custom pricing
  - Unlimited requests
  - Dedicated support
  - Custom SLA

**Recommendation**: Start with free tier for development. For production, consider paid plan if you need more than 100 requests/day.

## GDELT Project

### Free Access ✅
- **Completely FREE** for all users
- **No API key required** for basic access
- **No rate limits** (but use responsibly)
- **Historical data**: 1979 to present
- **Real-time updates**: Every 15 minutes

### Access Methods:
1. **GDELT 2.0 API**: https://api.gdeltproject.org/
   - Free, no authentication needed
   - Rate limits: Reasonable use (not officially stated)
   
2. **GDELT Cloud Storage**:
   - Google BigQuery (free tier available)
   - Google Cloud Storage buckets

3. **GDELT Website**: https://www.gdeltproject.org/
   - Direct file downloads
   - CSV, JSON formats

**Note**: GDELT is funded by Google Ideas and is completely free for research and commercial use.

## Alternative Free News Sources

### 1. **RSS Feeds** (Free)
- Many news sites provide free RSS feeds
- No API key needed
- Examples: Reuters, Bloomberg, Financial Times

### 2. **Reddit API** (Free)
- Free tier available
- Good for sentiment analysis
- Subreddits: r/commodities, r/trading

### 3. **Twitter API** (Free Tier Available)
- Free tier: 1,500 tweets/month
- Good for real-time news
- Requires Twitter Developer account
